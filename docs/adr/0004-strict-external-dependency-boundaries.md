# Strict Boundaries Around External Package Dependencies

`gh-migration-tool` depends on [`ilegra/gh-repo-sync`](https://github.com/ilegra/gh-repo-sync) (`v1.1.1`) for repository synchronization and [`ilegra/gh-migration-inventory-manager`](https://github.com/ilegra/gh-migration-inventory-manager) (`v1.3.7`) for Google Sheets inventory tracking. To prevent brittle coupling to internal modules we do not control in this repository, `gh-migration-tool` must only consume those libraries through their public domain entrypoints (`SyncConfig`/`SyncManager` in Step 4 and `Inventory.update_progress` in Step 6). Internal transport clients or scraper utilities inside those dependencies (such as `JenkinsClient`) must not be imported by `gh-migration-tool` stages; only credential settings may be shared.
